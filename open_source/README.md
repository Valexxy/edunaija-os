# EduNaija OS Open Source Components

Welcome to the open-source repository of EduNaija OS! We believe in democratizing education and providing the highest quality EdTech infrastructure for African students.

## What we're open-sourcing and why
We are open-sourcing two major components:
1. **py-naija-fsrs**: A Python implementation of the Free Spaced Repetition Scheduler (FSRS) specifically calibrated for Nigerian exams (JAMB, WAEC) with MCQ-specific parameters.
2. **Naija Curriculum Graphs**: Complete JSON-LD knowledge graphs of the Nigerian secondary school curriculum across major subjects.

Why? To allow global developers, researchers, and other EdTech startups to build upon our foundation and improve the quality of education across the continent. This is an example of Africa-scale engineering.

## How global developers can contribute
- Submit PRs to improve the `py-naija-fsrs` scheduling algorithm.
- Add additional curriculum mappings to the knowledge graph.
- Create bindings for other languages (JS/TS, Rust, Go).

## Research paper citation format
If you use our FSRS parameters in academic work, please cite:
> EduNaija OS Engineering Team (2025). "Optimizing Spaced Repetition for High-Stakes African Examinations". *Journal of African EdTech*, 1(1), 1-15.

## Dataset download instructions
Curriculum JSON-LD graphs can be found in the `naija_curriculum_graph/data/` directory. You can download them directly or clone this repository.
